See folder "03.02 Build JAVA Hello world".

Create folder for building Docker image: ~/Docker/java-hello-world

Put in folder file "HelloWorld.java"

Run:

javac HelloWorld.java

Put in folder file "Dockerfile"

Run:

docker build -t my-java-hello-world:1.0 .

Run one of:
docker run my-java-hello-world:1.0

docker run --rm --name hw my-java-hello-world:1.0
