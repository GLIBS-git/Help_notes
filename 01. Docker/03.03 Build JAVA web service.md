See folder "03.02 Build JAVA web service".

1. Create folder for building Docker image: ~/Docker/java-web-service

2. Put in folder file "RestWebService.java"

3. Run:
   
javac RestWebService.java

5. Put in folder file "Dockerfile"

6. Run:

docker build -t java-web-service:1.0 .

7. Run one of:

docker run --name jws -d -p 5050:5050 java-web-service:1.0

docker run --name jws -d -p 0.0.0.0:5050:5050 java-web-service:1.0
