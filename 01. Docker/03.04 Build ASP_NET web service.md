1. Create folder for building Docker image: ~/Docker/cs-web-service

2. Put in folder the whole ASP.NET web service project.

3. Run:

docker build -t cs-web-service:1.0 .

4. Run one of:

docker run --name csws -d -p 5050:5050 cs-web-service:1.0
docker run --name csws -d -p 0.0.0.0:5050:5050 cs-web-service:1.0
